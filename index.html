Hisab — Personal Finance & Bookkeeping

A mobile-first, installable PWA for one person, storing everything locally in BDT. No backend, no registration, no cloud. This document translates the page specification into a concrete visual system and a set of screen designs covering the primary navigation, transaction entry, import review, and security flows.
